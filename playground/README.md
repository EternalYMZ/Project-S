# Project S playground

## Generate a product table

Run `python product_gaps.py 1000000000 11 12` to print all 45 distinct gaps of the form 11^i 12^j below one billion, in execution order. Both exponents start at zero, so the table ends in 1. Generation uses only the input length and the two bases. This constructs a specified family; the output carries no optimality guarantee.

## Count key comparisons

Build count.cpp with MSVC in an x64 developer prompt using `cl /EHsc /O2 /std:c++17 /openmp count.cpp`. Give count.exe the length, shuffle seed, whitespace-separated gap file, and thread count. The output reports comparisons and right shifts per pass and checks the final ranks. The generator and counter can also be used separately.

On Windows, run the following in PowerShell 7 (UTF-8 output):

    python product_gaps.py 1000 2 3 > gaps.txt
    ./count.exe 1000 42 gaps.txt 2

With the MSVC benchmark executable this case produced 34,343 comparisons and 4,246 shifts. For small arrays the counter also checks each pass against a separate adjacent-exchange implementation. Random permutations are generated by the C++ library shuffle using mt19937_64; replaying exact seed results requires the same shuffle implementation. At one billion keys the main array takes 4 GB. At gaps 644 and 301 the existing instrument additionally emits sampled checkpoint files in the working directory.
